# tamako

撮影した動画を **撮影順に並べ → 不要な区間を切り → 顔を PNG で隠し → あとから録った声で字幕を付ける** ところまでを自動化する道具です。Windows で動きます。

Filmora は必要ありません。すべて自動で mp4 まで書き出します。あとから Filmora で手直ししたい場合のために、カット位置の一覧も同時に出します。

---

## 最初に読んでほしいこと（顔隠しについて）

**顔検出は完璧ではありません。この道具の出力を確認せずに公開しないでください。**

顔の検出には機械学習の検出器（YuNet）を使っています。正面を向いた顔はよく当たりますが、以下の場合は外すことがあります。

- 真横を向いている、後ろを向いている
- 手や物で顔が隠れている
- 動きが速くてぶれている
- 極端に暗い、逆光
- 顔がとても小さく写っている

外した瞬間、そのフレームは**素顔が出たまま書き出されます**。対策として次の 3 つを入れてあります。

1. 検出を見失っても、直前の位置に 0.7 秒は隠し続ける（`mask.hold_sec`）
2. 検出枠の 2.0 倍を隠す。検出器が返す枠は目・鼻・口だけの狭いもので、そのままでは髪や顎が出ます（`mask.scale`）
3. 「顔をひとつも検出しなかったフレーム」の時刻を報告書に記録する

それでも保証はできません。**書き出したあと必ず全編を目で確認してください。** 実行後に出る「顔隠しの確認」の数字と `output/edit_report.json` の `times_without_any_face` が、どこを重点的に見るべきかの手がかりになります。

## 準備（初回だけ）

### 1. Python を入れる

[python.org](https://www.python.org/downloads/windows/) から **Python 3.10 以降** を入れます。
インストール画面で **「Add python.exe to PATH」に必ずチェック**を入れてください。ここを忘れると動きません。

### 2. セットアップを走らせる

このフォルダの `scripts\setup.bat` をダブルクリックします。仮想環境を作り、必要なものを入れ、顔検出モデルを取得し、`config.json` を作ります。数分かかります。

ffmpeg は自動で入るので、別途インストールする必要はありません。

### 3. 素材を置く

- `input` フォルダに、撮影した動画を全部入れる（サブフォルダは見ません）
- 顔に重ねたい画像を **`mask.png`** という名前でこのフォルダに置く
  - 透過 PNG を推奨します。透過が無い画像でも動きますが、四角く貼り付いた見た目になります
  - 正方形に近い画像が扱いやすいです

## 使い方

工程は 2 つに分かれています。あいだに「あなたが確認して声を録る」という作業が入るためです。

### 前半 — 並べる / 切る / 顔を隠す

`scripts\1_edit.bat` をダブルクリックします。

1. まず**下見**が出ます。どの順に並ぶか、どこが切られるかが表示され、まだ書き出しません
2. 内容がよければ `y` を入れて Enter。書き出しが始まります
3. `output\edited.mp4` ができます

切りすぎ・切らなすぎのときは `config.json` を直してもう一度実行してください（後述の「切り方の調整」を参照）。

### あなたの作業

`output\edited.mp4` を再生して確認します。**顔が隠しきれていない箇所が無いか、ここで必ず見てください。**

問題なければ、その映像を見ながら声を録音します。録音は Windows の「ボイスレコーダー」でも、お使いの録音ソフトでも構いません。wav / mp3 / m4a などで保存してください。

映像とだいたい同じ長さになるように録るのがコツです。ずれている場合は実行時に警告が出ます。

### 後半 — 文字起こし / 字幕 / 音声の差し替え

`scripts\2_finish.bat` をダブルクリックし、録音した音声ファイルを窓にドラッグ＆ドロップして Enter。

1. 音声が文字起こしされ、`output\subtitles.srt` ができます
2. その字幕が映像に焼き込まれ、音声が差し替わります
3. `output\final.mp4` が完成品です

**初回は文字起こしモデルの取得に通信と時間がかかります**（`small` でおよそ 500MB）。2 回目以降はキャッシュされます。

### 字幕の文字を直したいとき

`output\subtitles.srt` をメモ帳などで開いて直し、`scripts\3_resubtitle.bat` を実行すると、文字起こしをやり直さずに焼き直せます。こちらは速いです。

## コマンドで使う

`.bat` は下のコマンドを呼んでいるだけです。細かく調整したいときは直接使ってください。

```
.venv\Scripts\activate.bat

tamako init [フォルダ]          設定ファイルとフォルダの雛形を作る
tamako check                    書き出さずに並び順とカット結果を見る
tamako edit                     並べる・切る・顔を隠す
tamako transcribe --audio 音声  文字起こしして SRT だけ作る
tamako subtitle --video 動画 --srt 字幕 [--audio 音声]   字幕を焼き込む
tamako finish --video 動画 --audio 音声                  上の 2 つをまとめて
```

設定より優先される引数がいくつかあります。

```
-i, --input   素材フォルダ
-o, --output  書き出し先
-m, --mask    顔に重ねる PNG
    --mode    any / both / silence / face
-c, --config  設定ファイルの場所
```

例：切り方だけ変えて下見する

```
tamako check --mode both
```

## 切り方の調整（config.json の `cut`）

| 設定 | 既定 | 意味 |
| --- | --- | --- |
| `mode` | `any` | `any` = 無音 **または** 顔なしを切る（最も短くなる）<br>`both` = 無音 **かつ** 顔なしのときだけ切る（最も安全）<br>`silence` / `face` = 片方だけを根拠にする |
| `silence_db` | `-32.0` | これより静かなら無音とみなす。切られすぎるなら `-40` に、残りすぎるなら `-25` に |
| `silence_min_sec` | `0.8` | この長さ以上続いた無音だけを対象にする |
| `face_analysis_fps` | `3.0` | 顔の有無を調べる細かさ。上げると正確だが遅い |
| `face_hold_sec` | `1.0` | この長さ以下の検出の途切れは無視する。細切れのカットを防ぐ |
| `padding_sec` | `0.25` | 残す区間の前後に足す余白。語頭・語尾が切れるなら増やす |
| `min_keep_sec` | `0.6` | これより短い残り区間は捨てる |
| `min_cut_sec` | `0.5` | これより短いカットは行わない |

**まず `tamako check` で下見してから調整してください。** 書き出しは時間がかかるので、切り方が決まってから `edit` するのが効率的です。

### よくある調整

- **切られすぎる** → `mode` を `both` にする。それでも足りなければ `silence_db` を `-40` に、`min_cut_sec` を `1.0` に
- **無音が残る** → `silence_db` を `-25` に、`silence_min_sec` を `0.5` に
- **話し始めが切れる** → `padding_sec` を `0.5` に
- **カットが細切れで見づらい** → `min_cut_sec` と `min_keep_sec` を増やす

## 顔の隠し方の調整（config.json の `mask`）

| 設定 | 既定 | 意味 |
| --- | --- | --- |
| `score_threshold` | `0.5` | 顔と判定する確信度。**下げるほど多く隠す**（安全側） |
| `scale` | `2.0` | 検出枠の何倍を隠すか。`1.6` だと髪が角から出ます |
| `offset_y` | `0.0` | 上下の微調整（顔の高さに対する割合、負で上）。髪が多いなら `-0.1` 前後 |
| `hold_sec` | `0.7` | 見失っても直前の位置に出し続ける長さ |
| `detect_width` | `640` | 検出用に縮小する幅。小さいほど速いが小さい顔を見逃す |
| `detect_every_n_frames` | `1` | `1` なら毎フレーム検出。**安全のため 1 のままを推奨** |

**隠し漏れがあった場合**は、`score_threshold` を `0.3` に下げ、`scale` を `2.4` に上げ、`hold_sec` を `1.5` に伸ばして再実行してください。隠しすぎるぶんには安全です。

## Filmora で手直しする

`output\cut_list.csv` に、どの素材のどこを使ったかがタイムコードで並んでいます。Excel で開けます。

| 順番 | 出力開始 | 出力終了 | 長さ(秒) | 元ファイル | 元の開始 | 元の終了 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 00:00:00.000 | 00:00:02.250 | 2.250 | b_clip.mp4 | 00:00:00.000 | 00:00:02.250 |

この表を見ながら Filmora のタイムラインで元素材を並べ直せば、自動判定を土台にして手で詰められます。`output\edit_report.json` にはさらに詳しい記録（検出された無音区間、顔が無い区間、確信度の低かった検出の時刻など）が入っています。

なお、Filmora のプロジェクトファイル（`.wfp`）を直接生成することはしていません。非公開フォーマットで、壊れたファイルを作ってしまう危険があるためです。

## 困ったとき

**「Python が見つかりません」**
インストール時に「Add python.exe to PATH」を入れ忘れています。Python を入れ直すか、環境変数 PATH に追加してください。

**「顔検出モデルを取得できませんでした」**
ネットワークかセキュリティソフトが通信を止めています。社内ネットワークなどで塞がれている場合は、
`https://media.githubusercontent.com/media/opencv/opencv_zoo/main/models/face_detection_yunet/face_detection_yunet_2023mar.onnx`
を手動で入手し、`%LOCALAPPDATA%\tamako\face_detection_yunet_2023mar.onnx` に置いてください。

**「文字起こしモデルを用意できませんでした」**
同じく通信の問題です。`config.json` の `subtitle.model` を `tiny` や `base` にすると軽くなります。精度を上げたいなら `medium` にしてください（そのぶん遅く、容量も要ります）。

**字幕が豆腐（□□□）になる**
`config.json` の `subtitle.font` に、その PC に入っているフォント名を書いてください。Windows なら `Yu Gothic UI` `Meiryo` `MS Gothic` あたりが確実です。

**「残す区間がひとつもありません」**
条件が厳しすぎます。`mode` を `both` にするか、`silence_db` を下げるか、`min_keep_sec` を小さくしてください。

**書き出しが遅い**
`config.json` の `encode.preset` を `veryfast` にすると速くなります（ファイルは少し大きくなります）。`mask.detect_width` を `480` に下げるのも効きますが、小さく写った顔を見逃しやすくなるので注意してください。

## 仕組み

```
input/*.mp4
  ├─ 撮影時刻のメタデータで並べ替え（無ければファイル更新時刻）
  ├─ ffmpeg silencedetect で無音区間を検出
  ├─ YuNet で顔の有無を 3fps で走査
  ├─ 2 つを突き合わせて残す区間を決定
  ├─ 残す区間を繋ぎながら、毎フレーム顔を検出して PNG を合成
  └─ 音声も同じ区間で切って結合 → output/edited.mp4
       ↓（あなたが確認し、声を録る）
  ├─ Whisper で文字起こし → output/subtitles.srt
  └─ 字幕を焼き込み、音声を差し替え → output/final.mp4
```

映像の符号化は 1 回だけです。「切ってから重ねる」で 2 回符号化すると画質と時間を損なうため、切り出したフレームにその場で合成して書き出しています。

## 開発者向け

```
src/tamako/
  config.py      設定の読み込み（コメント付き JSON）
  ffmpeg.py      ffmpeg/ffprobe の場所探しとメタデータ取得
  frames.py      生フレームの読み書き（ffmpeg パイプ）
  ordering.py    撮影順の並べ替え
  silence.py     無音区間の検出
  faces.py       顔検出（YuNet）とモデル管理
  segments.py    区間演算とカット判定（動画に触れない純粋な計算）
  overlay.py     PNG 合成と追従
  render.py      前半の書き出し
  transcribe.py  文字起こしと SRT
  subtitle.py    字幕の焼き込みと音声差し替え
  pipeline.py    解析の段取り
  cli.py         コマンド行の入口
```

顔の取りこぼしを減らすための計画は `docs/face-coverage-plan.md` にまとめてあります。

試験を走らせる:

```
python tests/test_segments.py      # 区間演算・カット判定
python tests/test_transcribe.py    # 字幕の組み立て
python tests/make_fixtures.py 出力先   # 検証用の合成素材を作る
```

`make_fixtures.py` は、実写の顔が動き、途中で画面外に出て、無音区間もある動画を 2 本作ります。実素材なしで全工程を検証できます。ファイル名の順と撮影時刻の順がわざと食い違うようにしてあるので、並べ替えの検証にもなります。
