# tamako

撮影した動画を **撮影順に並べ → 不要な区間を切り → 顔を PNG で隠し → あなたが仕上げ → あとから録った声で字幕を付ける** ところまでを自動化する道具です。Windows で動きます。

Filmora は必要ありません。すべて自動で mp4 まで書き出します。あとから Filmora で手直ししたい場合のために、カット位置の一覧も同時に出します。

---

## 最初に読んでほしいこと（顔隠しについて）

**顔検出は完璧ではありません。この道具の出力を確認せずに公開しないでください。**

顔の検出には機械学習の検出器（YuNet）を使っています。正面を向いた顔はよく当たりますが、以下の場合は外すことがあります。

- 真横を向いている、後ろを向いている
- 手や物で顔が隠れている
- 動きが速くてぶれている
- 極端に暗い、逆光
- 顔がとても小さく写っている

**そこでこの道具は、「自動で最大限隠し、残りをあなたが直せる状態にする」という作りになっています。** 自動で 100% 隠すことは原理的にできないので、目標をそこに置いていません。

自動側の備えは 4 つです。

1. **検出が途切れても、前後から位置を推定して隠し続ける。** 前後どちらにも検出があれば補間し、片側しか無ければ直前の速度で外挿します。推定が外れるぶんは箱を大きくして吸収します（動きが速いほど大きく）
2. **`mask.png` の透明部分を計算に入れる。** 隠しているのは四角ではなく PNG の不透明な画素なので、丸いステッカーなら角から顔が出ます。実際に隠れる範囲を測って、重ねる大きさを自動で補正します
3. **確認すべき箇所を、危険度順に絞って出す。** 「何も隠していない」「位置を保証できない」「推定だけで覆っている」箇所を区間単位でまとめ、危ない順に並べます。**音が鳴っているのに顔が見つからない箇所**は、人が写っている可能性が高いので特に上に来ます
4. **あなたが直したものは記録に残り、次回以降も効きます。** 設定を変えて出し直しても消えません

**それでも保証はできません。書き出したあと必ず全編を目で確認してください。**

## 準備（初回だけ）

### 1. Python を入れる

[python.org](https://www.python.org/downloads/windows/) から **Python 3.10 以降** を入れます。
インストール画面で **「Add python.exe to PATH」に必ずチェック**を入れてください。ここを忘れると動きません。

### 2. セットアップを走らせる

このフォルダの `scripts\setup.bat` をダブルクリックします。仮想環境を作り、必要なものを入れ、顔検出モデルを取得し、`config.json` を作ります。数分かかります。

ffmpeg は自動で入るので、別途インストールする必要はありません。

### 3. 素材を置く

- `input` フォルダに、撮影した動画を全部入れる（サブフォルダは見ません）
- 顔に重ねたい画像を **`mask.png`** という名前でこのフォルダに置く
  - 透過 PNG を推奨します。透過が無い画像でも動きますが、四角く貼り付いた見た目になります
  - 正方形に近い画像が扱いやすいです

## 使い方

工程は 3 つに分かれています。

```
1) 自動で隠す          tamako edit
      ↓
2) 確認して直す        tamako remask → tamako fix    ← 納得するまで往復
      ↓
3) 声を録って字幕      tamako finish
```

### 1) 自動で隠す

`scripts\1_edit.bat` をダブルクリックします。

1. まず**下見**が出ます。どの順に並ぶか、どこが切られるかが表示され、まだ書き出しません
2. 内容がよければ `y` を入れて Enter。書き出しが始まります
3. `output\edited.mp4` ができます
4. 最後に **要確認の箇所が危険度順**に表示されます

### 2) 確認して直す

**要確認が 0 箇所なら、この工程は飛ばして構いません。**

`scripts\1b_fix.bat` をダブルクリックすると、確認用の書き出し → 要確認の一覧 → 反映まで通しでやってくれます。コマンドで使う場合は次の 2 つです。

```
tamako remask     要確認の箇所の前後だけを短く書き出す（output\_review\review.mp4）
tamako fix        その箇所を危険度順に一覧で出す
```

`remask` は**素材と同じ解像度**で書き出します。粗い画質にすると「顎が少し出ている」ような漏れが見えなくなるためです。短いので、10 分の動画でも確認は 1〜2 分で終わります。

`tamako fix` は、危険度の高い箇所から順に一覧で見せます。

> **箱を直す画面は入れ替え作業中です。** これまでの OpenCV の窓は削除しました。窓はリサイズすると座標がずれ、日本語が描けず、そして何より**要確認箇所の外を見られない**——機械が気づかなかった漏れを直せないのでは、この道具の目的そのものに反します。置き換え先はブラウザの画面です。それまでは `remask` で確認し、`output\.tamako_work\faces_manual.jsonl` を直接編集するか、次の版をお待ちください。

直した内容は `output\.tamako_work\faces_manual.jsonl` に残ります。**`tamako edit` をもう一度実行すると、その修正を反映した状態で書き出し直されます。** 顔検出はやり直さないので速いです。

一部だけ本番画質で確かめたいときは：

```
tamako edit --only 00:03:10-00:03:20
```

### 3) 声を録って字幕を付ける

`output\edited.mp4` を再生しながら録音します。Windows の「ボイスレコーダー」でも、お使いの録音ソフトでも構いません。wav / mp3 / m4a などで保存してください。

`scripts\2_finish.bat` をダブルクリックし、録音した音声ファイルを窓にドラッグ＆ドロップして Enter。

1. 音声が文字起こしされ、`output\subtitles.srt` ができます
2. その字幕が映像に焼き込まれ、音声が差し替わります
3. `output\final.mp4` が完成品です

**初回は文字起こしモデルの取得に通信と時間がかかります**（`small` でおよそ 500MB）。2 回目以降はキャッシュされます。

字幕の文字を直したいときは `output\subtitles.srt` を編集して `scripts\3_resubtitle.bat` を実行すると、文字起こしをやり直さずに焼き直せます。

## コマンドで使う

```
.venv\Scripts\activate.bat

tamako init [フォルダ]          設定ファイルとフォルダの雛形を作る
tamako detect                   顔検出だけを先に走らせる（結果はキャッシュされる）
tamako check                    書き出さずに並び順とカット結果を見る
tamako edit                     並べる・切る・顔を隠す
tamako remask                   要確認の箇所だけを短く書き出す
tamako fix                      要確認の箇所を危険度順に一覧で出す
tamako selftest                 確認用と本番で同じものを描いているか検査する
tamako transcribe --audio 音声  文字起こしして SRT だけ作る
tamako subtitle --video 動画 --srt 字幕 [--audio 音声]   字幕を焼き込む
tamako finish --video 動画 --audio 音声                  上の 2 つをまとめて
```

設定より優先される引数：

```
-i, --input   素材フォルダ
-o, --output  書き出し先
-m, --mask    顔に重ねる PNG
    --mode    any / both / silence / face
-c, --config  設定ファイルの場所

edit --only 開始-終了   その範囲だけを本番画質で書き出す
edit --diagnostic       マスクの代わりに「実際に隠れる範囲」を色で塗る
fix  --list             一覧だけを出す
```

**顔検出は 1 回だけ走ります。** 結果は `output\.tamako_work\detect` に保存され、素材と検出設定が変わらない限り再利用されます。マスクの大きさを変えて出し直すのは速いです。

## 切り方の調整（config.json の `cut`）

| 設定 | 既定 | 意味 |
| --- | --- | --- |
| `mode` | `any` | `any` = 無音 **または** 顔なしを切る（最も短くなる）<br>`both` = 無音 **かつ** 顔なしのときだけ切る（最も安全）<br>`silence` / `face` = 片方だけを根拠にする |
| `silence_db` | `-32.0` | これより静かなら無音とみなす。切られすぎるなら `-40` に、残りすぎるなら `-25` に |
| `silence_min_sec` | `0.8` | この長さ以上続いた無音だけを対象にする |
| `face_score_threshold` | `0.6` | カット判定で「顔がある」とみなす確信度 |
| `face_hold_sec` | `1.0` | この長さ以下の検出の途切れは無視する |
| `padding_sec` | `0.25` | 残す区間の前後に足す余白。語頭・語尾が切れるなら増やす |
| `min_keep_sec` | `0.6` | これより短い残り区間は捨てる |
| `min_cut_sec` | `0.5` | これより短いカットは行わない |
| `detect_width` | `640` | カット判定用の検出解像度。**マスク用とは別です**（カットは誤検出で残りすぎるのが困り、マスクは見逃しが困る、という非対称があるため） |

**まず `tamako check` で下見してから調整してください。**

### よくある調整

- **切られすぎる** → `mode` を `both` にする。それでも足りなければ `silence_db` を `-40` に、`min_cut_sec` を `1.0` に
- **無音が残る** → `silence_db` を `-25` に、`silence_min_sec` を `0.5` に
- **話し始めが切れる** → `padding_sec` を `0.5` に
- **カットが細切れで見づらい** → `min_cut_sec` と `min_keep_sec` を増やす

## 顔の隠し方の調整（config.json の `mask`）

| 設定 | 既定 | 意味 |
| --- | --- | --- |
| `score_threshold` | `0.5` | 顔と判定する確信度。**下げるほど多く隠す**（安全側） |
| `scale` | `2.0` | 検出枠の何倍を隠すか。**`mask.png` の透明部分に応じて自動で補正されます**（丸い画像なら 2.7 倍前後になります） |
| `offset_y` | `0.0` | 上下の微調整（顔の高さに対する割合、負で上）。髪が多いなら `-0.1` 前後 |
| `hold_sec` | `0.7` | 検出が切れたあと、外挿で覆い続ける長さ |
| `detect_width` | `640` | 検出用に縮小する幅。**大きいほど小さい顔に強くなります**（`1280` にすると引きの画の顔が拾えますが、検出時間は 4 倍前後） |
| `dilate_frames` | `2` | 前後これだけのフレームの箱も取り込む（保険）。大きくすると動く人の軌跡ぜんぶを覆うことになります |
| `expand_per_velocity` | `0.5` | 推定の不確かさを箱の大きさで吸収する強さ |
| `expand_limit` | `4.0` | 広げる上限（倍）。ここに達した箱は「位置を保証できない」として報告されます |
| `uncovered_policy` | `expand` | 覆えない箇所の扱い。`expand` = 推定できる範囲を大きめに覆う／`cut` = その区間を出力から落とす／`warn` = 報告だけ |

**隠し漏れがあった場合**は、まず `score_threshold` を `0.3` に下げ、`detect_width` を `1280` に上げて再実行してください。それでも残るなら `tamako fix` で直すのが早いです。

**確実に漏らしたくない場合**は `uncovered_policy` を `cut` にしてください。覆えない区間が出力から落ちるので、漏れは定義上ゼロになります。ただし**覆えたわけではなく、その部分を捨てているだけ**です（尺が短くなります）。

ぼかしやモザイクは使いません。隠し方は `mask.png` の重ね合わせだけに統一してあります。

## Filmora で手直しする

`output\cut_list.csv` に、どの素材のどこを使ったかがタイムコードで並んでいます。Excel で開けます。

| 順番 | 出力開始 | 出力終了 | 長さ(秒) | 元ファイル | 元の開始 | 元の終了 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 00:00:00.000 | 00:00:02.250 | 2.250 | b_clip.mp4 | 00:00:00.000 | 00:00:02.250 |

`output\edit_report.json` にはさらに詳しい記録（無音区間、顔が無い区間、要確認の箇所とその危険度）が入っています。

**顔隠しの修正は Filmora ではなく `tamako fix` を使ってください。** Filmora で直すと、その 1 本限りの作業になり（記録が残らず、設定を変えて出し直すと消えます）、書き出しで画質が 1 世代落ちます。

なお、Filmora のプロジェクトファイル（`.wfp`）を直接生成することはしていません。非公開フォーマットで、壊れたファイルを作ってしまう危険があるためです。

## 出力されるもの

| 場所 | 中身 | 人に渡してよいか |
| --- | --- | --- |
| `output\edited.mp4` | 顔を隠した映像 | ○（確認のうえで） |
| `output\final.mp4` | 字幕と声を入れた完成品 | ○（確認のうえで） |
| `output\cut_list.csv` | カット位置の一覧 | ○ |
| `output\edit_report.json` | 全記録と要確認の一覧 | ○ |
| `output\_review\` | 確認用の抜き出し。**素顔が写っている場合があります** | **✗** |
| `output\.tamako_work\` | 顔検出の結果と、あなたの修正の記録。**顔の位置の時系列が入っています** | **✗** |

**`output` フォルダごと誰かに渡さないでください。** `_review` と `.tamako_work` には素顔や顔の座標が残ります。渡すのは `edited.mp4` / `final.mp4` などのファイル単位にしてください。

## 困ったとき

**「Python が見つかりません」**
インストール時に「Add python.exe to PATH」を入れ忘れています。Python を入れ直すか、環境変数 PATH に追加してください。

**「顔検出モデルを取得できませんでした」**
ネットワークかセキュリティソフトが通信を止めています。社内ネットワークなどで塞がれている場合は、
`https://media.githubusercontent.com/media/opencv/opencv_zoo/main/models/face_detection_yunet/face_detection_yunet_2023mar.onnx`
を手動で入手し、`%LOCALAPPDATA%\tamako\face_detection_yunet_2023mar.onnx` に置いてください。

**「設定ファイルに未知のキーがあります」**
綴り間違いです。`mask.score_treshold` のように入れ子の中を間違えた場合も指摘されます。

**「文字起こしモデルを用意できませんでした」**
同じく通信の問題です。`config.json` の `subtitle.model` を `tiny` や `base` にすると軽くなります。

**字幕が豆腐（□□□）になる**
`config.json` の `subtitle.font` に、その PC に入っているフォント名を書いてください。Windows なら `Yu Gothic UI` `Meiryo` `MS Gothic` あたりが確実です。

**「残す区間がひとつもありません」**
条件が厳しすぎます。`mode` を `both` にするか、`silence_db` を下げるか、`min_keep_sec` を小さくしてください。

**要確認の箇所が多すぎる（10 分あたり 50 箇所以上）**
人が直す前に自動側を調整してください。`mask.scale` を上げる、`score_threshold` を下げる、`dilate_frames` を増やす、のどれかで大きく減ります。

**書き出しが遅い**
`config.json` の `encode.preset` を `veryfast` にすると速くなります。顔検出が遅い場合は `mask.detect_width` を下げますが、小さく写った顔を見逃しやすくなるので注意してください。

## 仕組み

```
input/*.mp4
  ├─ 撮影時刻のメタデータで並べ替え（無ければファイル更新時刻）
  │
  ├─ tamako detect ─ 全フレームに顔検出をかけ、素材の時刻をキーに保存
  │                   （クリップ単位で並列。結果はキャッシュされる）
  │
  ├─ tracks ───────── 検出をトラックに繋ぎ、途切れを補間・外挿で埋める
  │                   ここまで全部「素材の時間軸」で行う（カットの前）
  │
  ├─ ffmpeg silencedetect で無音区間を検出
  ├─ 顔の有無と無音を突き合わせて残す区間を決定
  ├─ 人手修正（faces_manual.jsonl）を重ねる ← 人手が常に勝つ
  │
  └─ 残す区間を繋ぎながら PNG を合成 → output/edited.mp4
       ↓（あなたが remask で確認し、fix で直す。納得するまで往復）
  ├─ Whisper で文字起こし → output/subtitles.srt
  └─ 字幕を焼き込み、音声を差し替え → output/final.mp4
```

映像の符号化は 1 回だけです。「切ってから重ねる」で 2 回符号化すると画質と時間を損なうため、切り出したフレームにその場で合成して書き出しています。**直して出し直すときも素材から読み直すので、何度直しても画質は劣化しません。**

トラックの後処理をカットの**前**に行うのは、カット境界で補間が効かなくなるのを避けるためです。区間ごとに処理すると、区間の先頭と末尾が片側の文脈しか持てず、いちばん弱い箇所で穴が開きます。

## 開発者向け

```
src/tamako/
  config.py      設定の読み込み（コメント付き JSON・未知キーは入れ子まで検査）
  ffmpeg.py      ffmpeg/ffprobe の場所探しとメタデータ取得
  frames.py      生フレームの読み書き（ffmpeg パイプ・精密トリム）
  timeline.py    出力フレーム ↔ 素材時刻 の対応。時間の権威
  ordering.py    撮影順の並べ替え
  silence.py     無音区間の検出
  faces.py       顔検出器（YuNet）とモデル管理
  detect.py      解析パス。全フレーム検出して faces.jsonl に落とす
  tracks.py      トラック構築と、途切れの補間・外挿・膨張
  segments.py    区間演算とカット判定（動画に触れない純粋な計算）
  sites.py       要確認箇所の集約と危険度
  manual.py      人手修正の記録とマージ、確認済みの管理
  fix.py         確認と修正の土台（画面は持たない）
  overlay.py     PNG 合成とマスクの実効被覆
  render.py      書き出し
  report.py      記録の書き出し
  transcribe.py  文字起こしと SRT
  subtitle.py    字幕の焼き込みと音声差し替え
  pipeline.py    解析の段取り
  cli.py         コマンド行の入口
```

試験を走らせる:

```
python tests/test_segments.py       区間演算・カット判定
python tests/test_timeline.py       時間軸の契約（フレームと素材時刻の対応）
python tests/test_stage0.py         画面端・マスクの実効被覆・設定の検査
python tests/test_tracks.py         トラック構築と補間・外挿
python tests/test_sites.py          サイト集約・危険度・覆えない区間の扱い
python tests/test_manual.py         人手修正のマージと確認済みの単調性
python tests/test_transcribe.py     字幕の組み立て
python tests/test_detect.py         解析パスとキャッシュ（合成素材を作る）
python tests/test_pipeline_e2e.py   全工程の通し（合成素材を作る）
python tests/make_fixtures.py 出力先   検証用の合成素材を作る
```

`make_fixtures.py` は、実写の顔が動き、途中で画面外に出て、無音区間もある動画を 2 本作ります。実素材なしで全工程を検証できます。ファイル名の順と撮影時刻の順がわざと食い違うようにしてあるので、並べ替えの検証にもなります。

顔の取りこぼしを減らすための計画と、その設計判断の理由は `docs/face-coverage-plan.md` にまとめてあります。
